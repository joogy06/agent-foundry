# =============================================================================
# requirements-optional.txt — S075 (#240)
#
# EVERY LINE IN THIS FILE IS OPTIONAL. The harness runs stdlib-only: 225 skills,
# the gates, the installer and the session hooks all work with none of it
# installed. This file exists so that "what am I missing, and what does it cost
# me?" has an answer, instead of being discovered one skill at a time.
#
#   pip install -r requirements-optional.txt                  # everything
#   python3 install.py --with-extras=documents,spreadsheets   # one capability
#   python3 skills/_meta/python_deps.py report                # what's missing
#
# NEVER install this silently and never make it a hard requirement. A locked-down
# enterprise box where `pip install` is refused must still get a working harness —
# turning "this skill cannot extract a PDF" into "the installer failed" is a
# strictly worse outcome.
#
# FLOORS, NOT PINS. `>=` states the version a skill was written against. Exact
# pins rot, and they fight with whatever else lives in the user's environment;
# these libraries are leaves, not a dependency tree we control. Run
# `dep-currency-check` to see what has moved.
#
# FORMAT. Ordinary pip syntax plus structured comments pip ignores:
#   @capability  the group name, used by --with-extras
#   @unlocks     what becomes possible
#   @skills      which skills are affected
#   @without     what actually happens when it is absent — the honest cost
#   # import:    the MODULE name, where it differs from the package name
# =============================================================================
