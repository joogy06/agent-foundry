## GitHub (technical roles) [AS_OF: 2026-06]

- Pin 6 repositories that represent the work you want to be hired for.
- Two deployed projects with live URLs + strong READMEs > ten tutorial clones (recruiter weighting — snapshot).
- At least one LLM-API project is an expected signal for many roles now.
- Profile README: short canonical bio + what you're working on + how to reach you.
- Keep commit history legible; a recruiter walks through, they don't audit.
- README essentials: what it does, live demo link, how to run, one architecture note, a result.

## LinkedIn (off-strategy mechanics only) [AS_OF: 2026-06]

- **Profile copy and content strategy live in `career-positioning`** (360Brew ranking, the 5 content pillars, Saves/Sends weighting). Point there.
- This skill's only LinkedIn concern: that your LinkedIn entity (name, title, dates) is consistent with the rest of your footprint, and that it appears in your `sameAs`.

## Bluesky [AS_OF: 2026-06]

- Skews developer / journalist / tech-policy; good for technical credibility and niche reach.
- Custom domain handle (`@you.dev`) doubles as a verification + canonical-link signal.
- Cadence over virality; reply and participate, don't broadcast.

## Threads [AS_OF: 2026-06]

- Mainstream scale; broader-audience reach than Bluesky.
- Better for general professional visibility than deep technical niche.

## X [AS_OF: 2026-06]

- Residual reach; declining as a sole bet. Keep a handle for consistency / search; invest only if your audience is genuinely still there.

## Substack / Newsletter [AS_OF: 2026-06]

- Distribution + search-indexed long-form that builds entity authority.
- Route the *drafting* to `content-writer` + `human-voice-writing`; this skill decides whether and where.
- Consistency of cadence matters more than length; an abandoned newsletter is a negative signal.

## YouTube / Community Platforms [AS_OF: 2026-06]

- A large share of AI-engine citations trace to community platforms (snapshot) — participation here disproportionately helps findability.
- Only commit if sustainable; a dead channel doesn't help.

## Platform-Selection Logic

1. Run the compliance gate (HARD RULE 2).
2. Where is your actual audience (hiring managers, peers, the community you want to be known in)?
3. Pick 1–2 platforms there. Don't spray.
4. Set a cadence you will keep for 90 days minimum.
5. Point every profile back to the canonical site; add each to `sameAs`.

## Cadence Realism Table (evergreen craft norm)

| Effort level | Sustainable rhythm | Note |
|---|---|---|
| Light | 1 substantive post/week on one platform | Most people can hold this |
| Medium | 2–3 posts/week + 1 long-form/month | Needs a content habit |
| Heavy | Daily + weekly long-form + video | Only if it's part of the job |

Pick the level you'll still be doing in month three, not month one.
