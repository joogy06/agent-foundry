# UK compliance for build pages

| Rule | What it means for the page | Source |
|---|---|---|
| CAP Code 3.7 (substantiation) | Hold documentary evidence for every objective claim before publishing. "Our pick" chosen on objective grounds (price, performance) needs **dated selection criteria**; "best", "fastest" need dated evidence across the market. The "our pick" label is **not** a safe harbour | [V] ASA CAP Code section 3 |
| CAP Code 3.33 and 3.34 (comparisons) | When the page compares with identifiable competitors: compare products **meeting the same need** (3.33), on **material, relevant, verifiable and representative** features (3.34) | [V] ASA CAP Code section 3 |
| CMA price transparency (CMA209) | The headline price includes **all mandatory charges** (3.3); VAT and unavoidable fees are mandatory charges (4.4) | [V] CMA209, 13 Feb 2026 |
| DMCC Act 2024 (in force 6 Apr 2025) | No drip pricing; no fake or undisclosed-incentive reviews | [S] CMS legal update |

Linux and SteamOS pages also need the written disclosures in [os-builds.md](os-builds.md) (Consumer Rights Act "as described").
