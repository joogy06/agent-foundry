# CV / Résumé Format Variants

Region and vertical conventions for `career-application-writer`. Volatile market figures live in `~/.claude/skills/career-coach/references/market-snapshot-2026-06.md`; the conventions below are evergreen craft norms.

---

## US Résumé vs UK/EU CV vs Banking Vertical

| Dimension | US Résumé | UK / EU CV | Banking vertical (US or UK) |
|---|---|---|---|
| Name of doc | "Résumé" | "CV" | "CV" (even in US banking, often "CV") |
| Length | 1 page early, 1–2 pages mid+ | 2 pages common; less length-anxious | Tight: 1–2 pages; committee skims fast |
| Photo | No (bias-avoidance) | Varies by country; UK = no; some continental EU = yes | No |
| Personal data (DOB, marital status) | Never | Some EU countries expect it; UK = no | No |
| Summary/profile line | Optional 2–3 lines | Common | Sharp 2-line positioning statement |
| "Skills" section label | Yes — quoted UI term of art | Yes | Yes; map to the role's scorecard |
| Tone | Achievement-forward, quantified | Achievement-forward; slightly more formal | Committee language (revenue / risk / controls / compliance) |
| References | "Available on request" or omit | Sometimes listed | Omit |

> **Implementer note:** "Skills" above is the conventional résumé/CV *section label* — a quoted UI term of art, not the family's "competency/capability" usage for personal growth.

## 2026 Norms (semantic-ATS era)

| Norm | Current guidance |
|---|---|
| File format | PDF is the safe default again (the "ATS can't read PDF" caution has largely reversed — snapshot) |
| Layout | Single column, standard headers — multi-column/creative layouts confuse extraction |
| Keywords | Express the concept + natural synonyms once; stuffing *lowers* semantic-match scores (snapshot) |
| Competency placement | High on the page, mapped to the posting's scorecard criteria first |
| Dates / titles | Must match LinkedIn exactly (screening tools cross-check — snapshot) |
| Links | LinkedIn / GitHub / portfolio where role-relevant |
| Quantification | ~70% of bullets carry a number or concrete outcome; outcome before tool |

## Section Order (default, adjust to fit)

1. Name + contact + links (LinkedIn / GitHub / portfolio)
2. Positioning statement (2 lines — who you are for *this* role)
3. Competencies (mapped to scorecard)
4. Experience (reverse-chronological; tailored bullets)
5. Education / certifications
6. (Optional) Selected projects — strong for tech roles with a GitHub footprint

## Worked Example — Banking Vertical (experience block)

> **Senior Engineer, Markets Technology — <Bank>** (2021–present)
> - Owned the post-trade reconciliation platform across three trading desks; cut daily manual break-investigation from ~4 hrs to under 30 min and closed two repeat internal-audit findings.
> - Led the model-risk evidencing workstream for an automated surveillance control; passed second-line review with no remediation actions.
> - Rebuilt the alert-tuning pipeline; reduced false-positive surveillance alerts by ~a third while keeping a clean second-line review.

Committee reads: revenue protected, risk reduced, controls made auditable, manual effort removed, audit findings closed. Tool choices are subordinate to outcomes.

## Worked Example — Generalist (experience block)

> **Engineering Lead — <Company>** (2020–present)
> - Got the support and engineering teams onto one weekly triage call; ticket reopen-rate fell by about a third over the quarter.
> - Shipped the self-serve onboarding flow; cut time-to-first-value for new accounts from days to under an hour.
> - Mentored three engineers to senior; two now lead their own areas.

Same craft: outcome before tool, quantified, specific, in the writer's own register.

## Format-Selection Logic

- Tech role, public projects matter → include "Selected projects" + GitHub link.
- Banking / regulated → committee language; omit photo, DOB, references.
- Continental-EU application → check whether that country expects a photo / personal data before omitting.
- Senior (15 yr+) → 2–3 pages acceptable; lead with scope and outcomes, compress early-career roles.
