# Audience Profiles

Adapt every presentation to the audience. Read the profile, apply the norms.

## Executive / C-Suite / Board

| Dimension | Norm |
|---|---|
| Slide count | 8-12 main deck + appendix for backup |
| Depth | Headlines and implications, not details |
| Tone | Authoritative, data-backed, understated |
| Titles | Action titles stating the takeaway |
| Data | Big numbers, trends, comparisons. No raw data. |
| Visuals | Clean charts with callout boxes. Minimal decoration. |
| Structure | BLUF or SCR — lead with the answer/recommendation |
| Decision | Every deck must state what is being asked of them |
| Time | 15-20 minutes max including discussion |
| Font size | 24pt+ body, 30pt+ titles |

## Technical / Engineering

| Dimension | Norm |
|---|---|
| Slide count | 10-20 (varies widely) |
| Depth | Detailed — architecture diagrams, code snippets, trade-off analysis |
| Tone | Precise, honest about trade-offs, no marketing language |
| Titles | Can be topic-based or action-based (either works) |
| Data | Benchmarks, latency numbers, throughput, error rates |
| Visuals | Architecture diagrams, sequence diagrams, data flow, system topology |
| Structure | ADR/RFC format — context, options, decision, consequences |
| Decision | Technical direction approval or peer review feedback |
| Time | 30-45 minutes with deep Q&A |
| Font size | 18pt+ body (can go smaller for code/diagrams) |

## Client / External / Sales

| Dimension | Norm |
|---|---|
| Slide count | 10-15 (Kawasaki 10/20/30 as baseline) |
| Depth | Value-focused, not implementation-focused |
| Tone | Polished, confident, persuasive but not pushy |
| Titles | Benefit-oriented action titles |
| Data | ROI, time-to-value, customer logos, case studies, proof points |
| Visuals | High-quality branded visuals, product screenshots, before/after |
| Structure | AIDA or Hook-Problem-Solution-Proof-CTA |
| Decision | Buy, partner, approve, next meeting |
| Time | 20-30 minutes |
| Font size | 28pt+ body, 36pt+ titles |

## Mixed / All-Hands / Town Hall

| Dimension | Norm |
|---|---|
| Slide count | 12-20 |
| Depth | Layered — headline for everyone, detail for those who care |
| Tone | Accessible, inclusive, avoids jargon |
| Titles | Action titles understandable by non-specialists |
| Data | Simple charts, headline metrics, progress indicators |
| Visuals | Mix of diagrams (simplified), photos, icons |
| Structure | What-So What-Now What or Before-During-After |
| Decision | Usually informational, sometimes vote/feedback |
| Time | 20-40 minutes |
| Font size | 24pt+ body |

## Banking / Regulatory / Steering Committee

| Dimension | Norm |
|---|---|
| Slide count | 10-12 main deck, extensive appendix |
| Depth | Data-driven, exception-focused, compliance-aware |
| Tone | Factual, precise, understated. No marketing language. |
| Titles | Action titles with specific metrics |
| Data | RAG status, KRIs, budget vs actual, risk heatmaps |
| Visuals | Dashboards, stoplight indicators, waterfall charts, risk matrices |
| Structure | Status-Progress-Risks-Next Steps or Exec Summary-Deep Dive-Appendix |
| Decision | Go/no-go, budget approval, risk acceptance |
| Time | 15 minutes max for main deck |
| Font size | 20pt+ body (dense but readable) |
| Special | Source line on every chart. Disclaimer on cover. Regulatory citations required. |
